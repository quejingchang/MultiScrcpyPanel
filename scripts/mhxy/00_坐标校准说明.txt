梦幻西游手游脚本坐标校准说明
================================
本目录下所有 .scr 脚本共用同一套 ANCHOR 锚点。
下面坐标基于 2026-08-13 游戏截图校准；如果你的界面比例/分辨率不同，
请修改每个脚本顶部的 ANCHOR 行，或在投屏画面上目测归一化比例。

通用锚点（基于截图）
--------------------
ANCHOR 活动入口 0.28 0.07   # 顶部「活动」按钮（从左到右：指引、活动、排行、挂机...）
ANCHOR 任务追踪 0.50 0.35   # 活动面板打开后，第一个可见/推荐任务条目
ANCHOR 自动     0.88 0.88   # 战斗界面右下角「自动」按钮
ANCHOR 自动任务 0.50 0.55   # 活动面板打开后，推荐任务/第一个可见任务的「参加/自动」按钮
ANCHOR 确认     0.50 0.62   # 弹窗中央「确认/确定」按钮
ANCHOR 返回     0.05 0.05   # 左上角返回按钮
ANCHOR 奖励     0.50 0.72   # 领奖弹窗的「领取」按钮
ANCHOR 关闭     0.92 0.15   # 弹窗右上角「关闭/X」按钮

重要提示
--------
1. 脚本假设你已在主界面（能看到顶部「活动」和右侧「任务」）。
2. 梦幻西游手游的活动面板是一个可滚动列表，不同日常任务的「参加」按钮位置不同。
   脚本里的 @自动任务 只对应面板中第一个可见/推荐任务的「参加」按钮。
   如果目标日常不在该位置，请先手动滚动到它再运行脚本，或调整 @自动任务 的 y 坐标。
3. 最稳的用法：先手动在活动面板里点开目标日常的「参加」（让角色进入自动寻路/战斗），
   再运行脚本负责「自动战斗→领奖→关闭→下一轮」的循环。
4. 每个任务一个脚本是为了方便你选择；里面流程是通用模板，
   特殊任务（如答题、门派闯关）可能需要你额外手动处理或后续加图像识别指令。

图标素材（FIND 指令自动定位任务）
----------------------------------
01_师门任务.scr 已改用 FIND 指令：在活动面板里自动匹配「师门.png」图标，
不再依赖固定坐标，因此每天任务位置变化也能找到。其余脚本同理可改用 FIND。

制作图标素材步骤：
  1) 连上设备，在活动面板里把目标日常（如师门）滚动到可见。
  2) 用截图工具裁出该任务的「图标」本体（背景尽量干净；透明 PNG 最佳，
     透明像素不计入匹配）。
  3) 保存到本目录下的 assets/ 子目录，命名与脚本里的 FIND 路径一致，
     例：scripts/mhxy/assets/师门.png（对应 01 脚本里的 assets/师门.png）。
  4) 运行脚本，日志显示「FIND 命中 (x,y)」或「FIND 未找到」：
     - 未找到：调小 MAXERR（更宽松，如 0.18）或重截更清晰的图标。
     - 找到但点错位置：微调 THEN TAP 后的偏移 dx dy（归一化，相对命中中心；
       参加按钮在图标下方→正 dy，在右侧→正 dx）。

注意：FIND 匹配基于当前投屏帧分辨率，截图标时请用与运行时相同的画质/分辨率
（「画质」下拉选标准档即可），跨分辨率相差过大可能失配。
