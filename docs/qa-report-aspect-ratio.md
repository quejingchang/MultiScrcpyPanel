## 4. 几何公式独立核算（AC-1 ~ AC-6）

### 4.1 100% 档核心公式

```
imgW = CardW − 4            // BorderStyle(1×2) + Padding(1×2) = 4
imgH = CardH − 94           // 4 + TitleHeight(26) + ButtonAreaHeight(64) = 94
r_card = imgW / imgH
```

## 5. ModelTests 断言改动专项判定

### 5.1 改动点

`MultiScrcpy.Tests/ModelTests.cs` 两条断言从 300/560 同步为 240/600：

- `:151/:152`：`AppConfig_默认值符合PRD()` —— 断言 `new AppConfig()` 的默认值。
- `:190/:191`：`AppConfig_归一化把越界值收敛回合法范围()` —— 断言 `Normalize()` 对非法值的回退结果。

### 5.2 是否属于「改测试掩盖问题」

**结论：不是掩盖问题，是正确更新契约锁。**

论证：

1. 这两个测试断言的是 `AppConfig` 类**公开的默认常量值**，而不是某个业务计算结果。
2. 本轮产品需求的核心就是把这些默认常量从 300/560 改为 240/600（P0-1 / P0-2）。常量已变，断言必须同步，否则测试会正确失败。
3. 非法值回退必须回到新的默认值 240/600，而不是旧值 300/560 —— 如果测试仍断言 300/560，反而会让非法配置回落到旧胖比例，违反 AC-7 和 P0-2。
4. 测试未删改任何逻辑：它仍然在验证「默认值是什么」和「非法值回退到什么」这两个不变量；变的只是预期值，与产品意图一致。
